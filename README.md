# 🎤 말로 입력하기

마이크에 대고 말하면 글자로 바꿔 주는 간단한 웹 페이지입니다. 설치할 것 없이 `index.html` 하나로 동작합니다.

## 기능
- 말하는 동안 실시간으로 글자 표시 (한국어 / English / 日本語)
- 적힌 글은 직접 고칠 수 있음
- 복사, `.txt` 파일 저장, 지우기
- 브라우저에 자동 저장 (새로고침해도 유지)

## 사용법
1. **Chrome, Edge 또는 Safari**에서 `index.html`을 엽니다.
   - 가장 쉬운 방법: GitHub 저장소 **Settings → Pages**에서 이 브랜치를 선택하면 `https://` 주소가 생깁니다.
   - 내 컴퓨터에서: `python3 -m http.server` 실행 후 `http://localhost:8000` 접속.
2. **말하기 시작** 버튼을 누르고 마이크 권한을 허용합니다.
3. 말을 마치면 **멈추기**를 누릅니다.

## 참고
- 음성 인식은 브라우저의 Web Speech API를 사용합니다. Firefox는 지원하지 않습니다.
- 마이크는 `https://` 주소나 `localhost`에서만 동작합니다.
- Chrome은 음성 인식에 인터넷 연결이 필요합니다.
